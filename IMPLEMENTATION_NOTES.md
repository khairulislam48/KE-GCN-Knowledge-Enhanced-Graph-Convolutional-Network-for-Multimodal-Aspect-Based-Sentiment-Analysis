# Implementation notes and reproduction status

## What this repository represents

This repository contains the four notebooks supplied for the KE-GCN project. The notebook filenames and source-level project identifiers have been rebranded from DPFN to KE-GCN. The model equations, experimental protocol, and scientific methodology have **not** been corrected in this packaging step.

## Dataset scope

The associated paper reports results on both Twitter-2015 and Twitter-2017. The supplied notebook configuration inspected for this package contains Twitter-2015-specific paths and splits. Do not assume that the uploaded notebook set already runs the full Twitter-2017 experiment without additional configuration or code.

## Evaluation caveat

The supplied training notebook selects checkpoints using test-set metrics during training. This means the resulting test scores should not be described as an independent, untouched test evaluation. This repository preserves that existing workflow; it has not been changed as part of the renaming step.

## Preprocessing caveat

The supplied preprocessing and training notebooks appear to expect some artifacts under different filenames, and the training notebook references feature files that are not all generated by the supplied preprocessing notebook. Before attempting an end-to-end run, compare the files produced by preprocessing with the paths loaded by training.

## External resources and paths

The notebooks reference Kaggle-specific paths, including:

- `/kaggle/input/piash-dpfn-mabsa-data`
- `/kaggle/input/piash-senticnet/senticnet.xlsx`
- `/kaggle/input/piash-conceptnet-cache/conceptnet_cache/conceptnet_cache_all_splits_cleaned.json`

These paths are environment-specific and are not GitHub-relative paths. Keep the external dataset directory names unchanged unless you also update the corresponding data locations in your environment.

## Reported paper results versus reproduced results

The paper reports:

- Twitter-2015: 78.50% accuracy and 74.91% Macro-F1.
- Twitter-2017: 72.37% accuracy and 70.22% Macro-F1.

These are paper-reported results. This repository does not claim that the current supplied notebooks independently reproduce them.

## What was changed in this package

- Notebook filenames were changed to KE-GCN names.
- Source-level model/function identifiers containing DPFN were renamed where straightforward.
- The external input path `/kaggle/input/piash-dpfn-mabsa-data` was preserved because it is an existing environment-specific data path.
- Saved notebook outputs were preserved.
- No methodological fixes, new experiments, or result verification were performed.
